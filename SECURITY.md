# Security Policy

## Supported Versions

This is a **public brand showcase repository** only.
It contains no application code, no credentials, no infrastructure and no customer data.

| Version | Supported |
|---------|-----------|
| main    | Brand assets only |

## Reporting a Vulnerability

If you discover a security issue related to the presencIA brand, website or services (not this repository):

1. **Do not** open a public issue
2. Email: **info@presencia.lat**
3. Include what you found, where, and how to reproduce it

Thank you for helping keep presencIA safe and trustworthy.
